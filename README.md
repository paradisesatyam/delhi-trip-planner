# 🏯 Delhi Trip Planner — AI Powered

An AI-powered travel planning web application that generates personalized day-by-day trip itineraries for Delhi using Groq AI.

## Setup

1. Install dependencies:
```
npm install
```

2. Create .env file:
```
VITE_GROQ_API_KEY=your_groq_api_key_here
```

3. Add your 6 images to the public folder:
- redfort.jpg
- indiagate.jpg
- lotustemple.jpg
- qutbminar.jpg
- humayuntomb.jpg
- connaughtplace.jpg

4. Run locally:
```
npm run dev
```

5. Build for production:
```
npm run build
```

## Tech Stack
- React.js + Vite
- Groq AI (mixtral-8x7b-32768)
- Vercel (hosting)
